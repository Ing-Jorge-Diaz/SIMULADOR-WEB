📝 FORMATOS ACEPTADOS:

Puedes escribir como en matemáticas:
────────────────────────────────────
EJEMPLO           →   EL PROGRAMA CONVIERTE A:
────────────────────────────────────
x^2               →   x**2
3x + 2            →   3*x + 2
sen(x)            →   Math.sin(x)
cos(x)            →   Math.cos(x)
tan(x)            →   Math.tan(x)
ln(x)             →   Math.log(x)
e^x               →   Math.exp(x)
√x                →   Math.sqrt(x)
π                 →   Math.PI
────────────────────────────────────
MÁS EJEMPLOS:
────────────────────────────────────
5 - 0.1x^2        →   5 - 0.1*x**2
4cos(x)           →   4*Math.cos(x)
sen(2x)           →   Math.sin(2*x)
e^(x^2)           →   Math.exp(x**2)
1/(1+x^2)         →   1/(1+x**2)
────────────────────────────────────
CONSEJOS:
• Usa ^ para potencias
• No necesitas * entre número y variable: 2x → 2*x
• Puedes usar sen, cos, tan (en español)
• Usa ln() para logaritmo natural
• π o pi para 3.1416
────────────────────────────────────
